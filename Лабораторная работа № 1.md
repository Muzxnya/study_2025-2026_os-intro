1. Ход работы
1.1. Создание виртуальной машины
В менеджере VirtualBox была создана новая виртуальная машина с именем Zhao Xinya os-intro. Тип операционной системы выбран Linux, версия Fedora (64-bit). Объём оперативной памяти выделен в размере
8192МБ, виртуальный жёсткий диск создан объёмом 25 ГБ. 
1.2. Установка операционной системы
В качестве оптического диска был подключён образ Fedora-Sway-Live-x86_64-41-1.4.iso. При загрузке в меню GRUB в строку, начинающуюся с linux, был добавлен параметр inst.text для запуска установки в текстовом режиме. Установка производилась в автоматическом режиме с использованием всего дискового пространства.
В процессе установки были заданы следующие параметры:
•	Часовой пояс: Europe/Moscow;
•	Пароль суперпользователя (root): установлен;
•	Пользователь: создан, имя пользователя ZhaoXinya, пользователю предоставлены права администратора.
1.3. Первый запуск и настройка
После завершения установки виртуальная машина была перезагружена. Система успешно загрузилась. Для проверки работоспособности были выполнены команды по просмотру информации о системе. 
2. Анализ системы
2.1. Информация о дисках
Была выполнена команда lsblk для просмотра структуры дисков. 
По результатам выполнения команды видно, что:
•	Устройство sda — основной виртуальный диск объёмом 25 ГБ.
•	Раздел sda2 смонтирован в /boot.
•	Раздел sda3 смонтирован в /home.
2.2. Информация о процессоре
Для получения информации о процессоре использована команда dmesg | grep -i "CPU". 
В выводе команды обнаружена строка, идентифицирующая процессор: 13th Gen Intel(R) Core(TM) i9-13900HX.
2.3. Информация об оперативной памяти
Информация об оперативной памяти получена с помощью команды dmesg | grep -i "Memory". 
Согласно выводу команды, системе доступно 8054888K / 8388152K (около 8 ГБ) оперативной памяти.
3. Контрольные вопросы
1.	Какую информацию содержит учётная запись пользователя?
Учётная запись пользователя содержит: имя пользователя, идентификатор пользователя (UID), идентификатор группы (GID), путь к домашнему каталогу, командную оболочку и зашифрованный пароль.
2.	Приведите примеры команд терминала:
o	man — получение справки по команде.
o	cd — перемещение по файловой системе (cd /home).
o	ls — просмотр содержимого каталога (ls -la).
o	du — определение объёма каталога (du -sh /home).
o	mkdir / rmdir — создание и удаление каталогов.
o	touch / rm — создание и удаление файлов.
o	chmod — задание прав на файл или каталог (chmod 755 script.sh).
o	history — просмотр истории команд.
3.	Что такое файловая система? Приведите примеры.
Файловая система — это способ организации, хранения и именования данных на носителе информации. Примеры: ext4, Btrfs, NTFS.
4.	Как посмотреть, какие файловые системы подмонтированы в ОС?
Для просмотра смонтированных файловых систем можно использовать команды df -h или mount.
5.	Как удалить зависший процесс?
Для принудительного завершения зависшего процесса необходимо узнать его идентификатор (PID) с помощью команды ps aux | grep <имя_процесса>, а затем выполнить команду kill -9 <PID>.
